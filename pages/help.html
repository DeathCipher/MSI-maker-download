Install help

How to install, update and remove MSI Maker.

Install MSI Maker

  1. Download the file

    Get MSI_Maker.msi and wait for the download to finish.

  2. Optional: verify it

    Compare the file’s SHA-256 checksum with the one on the download page.

  3. Run the installer

    Double-click the file and follow the on-screen steps.

If Windows shows a warning

“Windows protected your PC”

Windows can show this for installers it does not recognise. Only continue if the checksum matches the one on the download page: choose More info, then Run anyway.

Questions

Which systems does it run on?

MSI Maker is a Windows app and the .msi format is a Windows installer format. It is not for macOS or Linux.

Do I need the WiX Toolset?

No. MSI Maker does not need WiX.

Where are my settings stored?

Locally on your computer, so they are still there the next time you open the app.

How do I uninstall it?

Open Windows Settings, go to Apps, find MSI Maker in the list and choose Uninstall.
